# Heartfelt Dates

A personal apology-and-date website: one intimate gift she opens as a short journey, not a multi-user app.

## Language

**Journey**:
The Viewer's fixed path through the gift: Envelope → Reveal → Date Plan.
_Avoid_: Flow, wizard, onboarding

**Envelope**:
The sealed opening screen; the Viewer opens it to begin the gift.
_Avoid_: Landing, gate, splash

**Apology**:
The sincere message that names the hurt and your intent to make it right; the emotional core of the gift.
_Avoid_: Note, letter copy, sorry text

**Reveal**:
The screen after the Envelope opens; it presents the Apology, then leads into the Date Plan.
_Avoid_: Letter page, quote page, interstitial

**Date Plan**:
The single planned outing next month; shown after the Reveal. It has one shared calendar date; Activities are ordered stops that day. Forward-looking only — not the Apology. v1 has no separate Our Story, Apologies, Planning, or product-style nav.
_Avoid_: Itinerary, schedule, trip, main site

**Activity**:
An ordered stop within the Date Plan. Each one has an image (remote URL), vibe tag, title, time that day (not its own calendar date), and description.
_Avoid_: Date idea, event, plan item

**Vibe**:
A short mood label on an Activity (e.g. Quiet, Candle-lit, Adventurous).
_Avoid_: Category, tag, chip

**Viewer**:
The girlfriend experiencing the Journey; she does not manage content. The live site never shows Edit, Remove, or add-Activity controls.
_Avoid_: User, guest

**Editor**:
You — the only person who adds, updates, or removes Activities (and Journey copy), by editing the data file and Publishing — not via controls on the live site.
_Avoid_: Admin, owner

**Publish**:
Making content changes visible to the Viewer by updating the site's data file and redeploying the static site.
_Avoid_: Save, sync, submit

**First Open**:
The Viewer's first completion of Envelope → Reveal; afterward, return visits go straight to the Date Plan. There is no path back to the Apology after leaving the Reveal.
_Avoid_: Onboarding complete, session, cookie consent
